Brachytherapy Education Tool
============================
 Cervical cancer is a major problem around the world, and one method of treatment is a radiation therapy technique called brachytherapy. However, this approach to treatment is not only unintuitive for students but very challenging to teach. This is only worsened by the limited software available being too complex for students learning the procedure for the first time. My project aims to help students gain an intuition for what brachytherapy does on the most basic level by simulating a 3D dose distribution of a procedure based on initial parameters defined by the user. Over the course of four modules, the complexity of the simulated procedure gradually increases, with the last one being very reflective of real clinical scenarios. This program is a web application using HTML and JavaScript, entirely human created, incorporating advanced computer science techniques which allow elegant communication between various elements of the page, the user input, and the data of the module itself. This tool has potential use all of the world to improve the way students learn this very complex cancer therapy method.
